E-commerce Platform

A full-stack E-commerce application developed using Spring Boot, React, and MySQL.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT Authentication
- MySQL
- React
- JavaScript
- Axios

Features

- User registration and login
- JWT-based authentication
- Role-based access control (Admin and Customer)
- Product management
- Shopping cart management
- Order placement and management
- RESTful APIs

Project Structure

- "backend/" – Spring Boot application
- "frontend/" – React application

Database

MySQL database: "ecommerce_db"

Running the Project

1. Configure your MySQL database.
2. Set the required database and JWT environment variables.
3. Run the Spring Boot backend.
4. Install frontend dependencies using "npm install".
5. Start the React frontend using "npm run dev".
